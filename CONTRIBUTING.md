# Contributing

orbit-site is a small, solo-maintained project: Orbit's public website.

**Outside pull requests are not accepted.** Bug reports are welcome and
read -- a page that does not load, a picture that is wrong, a doc that is
out of date -- but they are information for the maintainer rather than work
items, and changes are not taken from outside contributors. GitHub is a
read-only mirror: development happens on the maintainer's own GitLab, which
overwrites GitHub's branches after every merge, so anything merged on GitHub
is lost.

If something on the site misdescribes Orbit, the fix is usually in
[Orbit](https://github.com/tomlawesome/orbit) itself: the docs here are
imported from its repositories every night.
