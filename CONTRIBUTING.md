# Contributing

orbit-site is a small, solo-maintained project: Orbit's public website.

**Outside pull requests are not accepted.** GitHub is a read-only mirror:
development happens on the maintainer's own GitLab, which pushes the `dev` and
`main` branches to GitHub after every merge. The mirror never force-pushes: a
merge made on GitHub is not erased, but it makes that branch differ from GitLab's,
and the mirror stops updating it (and so stops releasing the site) until the
maintainer sorts it out by hand. Nothing is merged on GitHub.

If something on the site misdescribes Orbit, the fix is usually in
[Orbit](https://github.com/tomlawesome/orbit) itself: the docs here are
imported from its repositories every night.
